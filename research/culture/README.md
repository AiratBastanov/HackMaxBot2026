# Исследовательская проба открытого набора Минкультуры

Это отдельные read-only инструменты исследования, не интеграция приложения. Они не читают конфигурацию MAX, не открывают live-БД и не импортируют события. Нужны существующие Python 3.12 и curl; зависимости не добавляются.

Результат 23.09.2026: [обзор источника](../../docs/pivot/04_CULTURE_SOURCE_REVIEW.md), [обезличенные агрегаты и HTTP-метаданные](evidence-2026-09-23.json). Реальные тела ответов, ZIP-фрагмент и schema JSON остаются только в ignored `.review/culture/`.

Из корня проекта, каждая сетевая команда выполняется отдельно:

```powershell
python research/culture/probe.py schema
python research/culture/probe.py api-list
python research/culture/probe.py archive-head
python research/culture/probe.py archive-tail
python research/culture/probe.py archive-prefix
```

`api-list` без ключа ожидаемо дал 401; exit 2 означает неуспешный доступ, а не пустой набор. Ключи этот probe не принимает. Остальные адреса получены из официальных кнопок скачивания; API URL — из опубликованной спецификации. Для воспроизведения архивного фрагмента зафиксированы ETag и Range версии 12. При изменении файла ожидается отказ 412; смещения не переносить на другую версию. Это не механизм обновления афиши.

Бюджет серии в `.review/culture-probe/requests.json`: не более 12 операций / 8 MiB, одна команда за раз, ≤45 с на HTTP-операцию. Нет автоматических повторов, переходов на другой host, cookies, регистрации или отключения TLS. HEAD не загружает тело архива. Файлы существующего наблюдения не перезаписываются. Произвольные URL не принимаются.

Для локального анализа укажите сохранённый файл `*-archive-prefix.body` из `.review/culture-probe`. Наблюдение этой задачи воспроизводится по локальному файлу `.review/culture/c18-version-12-last-shard-prefix.body`:

```powershell
python research/culture/analyze.py .review/culture/c18-version-12-last-shard-prefix.body --as-of 2026-09-23
python -m unittest discover -s research/culture -p 'test_*.py' -v
```

Без `--as-of` используется фактическая дата запуска в UTC+03:00 и следующие 30 календарных дней. Анализ ограничен 4 MiB сжатых / 32 MiB распакованных данных и 10 000 завершённых JSON-объектов. Неполный хвост не считается записью; CRC полного ZIP member не проверяется. JSON-ошибка хвоста маркируется как непрочитанная часть, а не как полная валидная выгрузка. Инструмент не вычисляет рекомендации и не превращает ежедневные интервалы выставки в отдельные события.

Счётчики цен относятся к структурированным полям архивных записей: `FREE_DECLARED` не проверяет условия из описания; `EXACT_PUBLISHED` не подтверждает взрослый тариф или наличие билета; одиночное `price` без `maxPrice` не считается гарантированно точной ценой. `in_kazan` проверяет явную локаль/город в адресе места; он не разрешает все возможные географические конфликты и не является готовым production-геокодером. Даты без offset не угадываются. Event ID, интервалы и площадки считаются отдельно.

Десять тестов используют только `SYNTHETIC_FIXTURE`. Анализ настоящего фрагмента выполнен; сетевые результаты первичного исследования получены последовательными ограниченными curl-командами. Повтор всей серии после упаковки probe не требуется для документального checkpoint. Условия открытых данных разрешают повторное использование с источником: [Минкультуры России](https://opendata.mkrf.ru/item/license), [паспорт набора](https://opendata.mkrf.ru/opendata/7705851331-events). Здесь публикуются наши агрегаты, не исходные описания, медиа или payload.
