## Контролируемая установка и постоянная оценка

Оператор сохраняет собственные identity, секреты, имя Compose project и постоянный том. [Команды обновления](CATALOG_OPERATIONS.md#контролируемое-обновление-установленного-бота) останавливают единственный потребитель на время обновления, после чего Docker автоматически подготавливает пригодный reviewed каталог. SQLite и закладки сохраняются.

Для постоянного размещения поддерживается Webhook через HTTPS. Оператор задаёт хост/DNS, сертификат, секрет webhook, постоянный диск и резервирование; согласует период обслуживания и обновления источников. [Инструкция](ORGANIZER_CHECK.md#постоянный-webhook), [закрытый технический лист](PRIVATE_HANDOFF_TEMPLATE.md). Секреты передаются уполномоченным получателям по закрытому каналу.
