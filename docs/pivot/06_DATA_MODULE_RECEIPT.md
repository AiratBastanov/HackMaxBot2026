## Реализация

Один модуль [src/data](../../src/data) на существующих TypeScript/Node/zod, без новых зависимостей. Версия нормализованного контракта — **1**; runtime-валидация применяется при чтении снимка и при вызове selector. MAX/probe SQLite не используется.

- `kudago.ts`, `timepad.ts`, `http.ts`, `curl.ts`: схемы источника, ограниченные GET, строгая пагинация и отдельная проверка Timepad. Чужие host/path/next/redirect не переходят в сеть. Общий журнал учитывает попытки и decoded bytes, включая ошибки. Нет ключей, аккаунтов, cookies, proxy rotation или user/MAX identity.
- `contract.ts`, `normalize.ts`: namespaced event/occurrence/venue IDs, связи без декартовых произведений, режим времени, период/таймзона/длительность, часы и last entry, тип/применимость цены, admission unknowns, точный источник, отдельные ссылки, publication/update/retrieval и статус проверки. Отсутствующая деталь площадки сохраняет её ID с неизвестными полями. Разные события с похожими названиями не объединяются; Timepad не включён, межпровайдерная дедупликация не заявлена.
- Малый timetable parser принимает целиком недельные записи вида `вт–пт 10:00–18:00; сб, вс 11:00–17:00`, ежедневный режим, закрытые дни и интервалы через `/`. Любое неподдержанное исключение/сезонность/текст кассы оставляет расписание неизвестным. Неустановленное соответствие `days_of_week` API не угадывается. Часы площадки применяются только при `use_place_schedule`; экскурсии/игры не становятся свободным посещением от одних часов музея.
- `cache.ts`: validated read, запись во временный файл с fsync и атомарным rename, lock, отдельная последняя попытка. Failed/partial refresh не заменяет хороший полный снимок; пустая/более старая загрузка и смена live/synthetic режима также защищены. Повреждённый кеш отклоняется. Промежуточные downloads сохраняются отдельно; сбой после них не меняет retrieval time старого активного снимка.
- `select.ts`: чистая функция snapshot/query/clock. Сначала жёсткие условия; затем предпочтение категории, ближайшее подходящее время и ID. До трёх разных событий, без баллов качества. Сеанс требует конца/опубликованной длительности; свободный визит объясняет только пересечение часов, без длительности осмотра/дороги. Неизвестная цена не бесплатная, тариф не гарантирует билет. Статусы отдельно обозначают missing, stale, incomplete, insufficient facts, no-match и выход за scope.

Журнал запросов накопительный в каталоге операции. **Не удалять его ради обхода бюджета этой серии.** Для новой самостоятельной серии задаётся новый явный `--cache .cache/cultural-plan-YYYYMMDD`; существующие snapshots остаются читаемыми по пути.
