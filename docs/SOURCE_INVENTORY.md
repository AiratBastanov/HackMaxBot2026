Наблюдаемый доступ к включённым страницам — анонимный HTTP 200, без ключей, cookies аккаунта, CAPTCHA, обхода TLS или доступа. HTTP 200 и robots сами по себе **не являются лицензией**. Основание решения проекта: ограниченное самостоятельное изложение фактических сведений с прямой ссылкой, после просмотра указанных страниц и применимых опубликованных ограничений. Провайдерская лицензия/партнёрство не заявляется. При обнаружении конкретного несовместимого условия source policy закрывается. Использование редактируемых описаний, изображений, логотипов, отзывов, рекламных материалов не разрешено этой политикой.

`src/data/public-facts-policy.ts` фиксирует **каждый** допустимый источник, reviewed basis и срок повторного просмотра до 26.10.2026; его hash привязан к записи review вместе с hash снимка. `PUBLIC_FACTS` не является общим разрешением всех провайдеров. Старое `ADMITTED_TESTERS_FACTS` не открывает карточки новичку. Все отправки/edits/сохранённые и pending provider-операции проверяют действующую review; смена policy/hash/срока закрывает несовместимые факты.
