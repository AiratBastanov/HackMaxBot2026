| Остаток | Условие / конкретное завершение |
|---|---|
| Решение данных | Пользователь выбирает A или B; инженерный объём и пределы уже подготовлены в readiness |
| Клиентские подшаги | Только точный остаток после нового окна выше; одна разрешённая кампания использована и остановлена, F09 не выполнен; без назначения автоповтора |
| Реализация выбранного режима | Только после выбора: manifest/validity/labels/bookmarks для A либо источник/terms/source-specific gates для B; затронутые проверки |
| Размещение и доступ | Заполнить UNKNOWN host/origin/operator/start/end/evaluators, проверить выбранную инфраструктуру; отдельно разрешённый cutover и реальные webhook mobile/web |
| Итоговый комплект | Подтверждённые API/PDF/закрытые реквизиты/пользовательские документы; фиксированная source/runtime/data версия, clean benchmark ≤300 с и независимый запуск |

Следующее решение выпуска — **подтвердить A как демонстрационную версию на вымышленных данных либо выбрать B с указанным незавершённым объёмом**. Финальное утверждение и сдача не выполнены.
