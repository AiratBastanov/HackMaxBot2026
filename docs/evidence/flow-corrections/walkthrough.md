# Локальный walkthrough исправлений

Только вымышленные события и участник. Настоящие HTTP decoder/admission, worker, SQLite, renderer и outbox; MAX симулирован. Это не наблюдение мобильного или веб-клиента.

## 1. Выбрана экскурсия: сводка сохраняет тему

```text
🧪 Демо · событие вымышленное
📍 Казань · 6 апреля 2030 г.
12:00–18:00 (UTC+3)
Посетители: 1 взр., 0 дет.
Бюджет на вход для всех: до 1000 ₽.
Тема: Экскурсии.
Показать подходящие события?
```

Кнопки: Показать результаты · Город · Посетители · Дата · Время · Бюджет · Тема · Назад · Главная · Мои события

## 7. Синтетический HTTP 400 после фиксации удаления; новый ввод возвращает оставшуюся запись

```text
🧪 Демо · событие вымышленное
Мои события
1. Свет (экспозиция) (Выставка)
Казань · 6 апреля 2030 г. · 11:47–18:13 (Москва, UTC+3)
1 взр., 0 дет.
💰 200 ₽ за всех
```

Кнопки: Открыть 1 · Удалить 1 · Назад · Главная

Отказ `PUT /messages`, HTTP 400 / INVALID_REQUEST, внедрён локально после удаления. Запись удалена до сети; одинаковый POST не отправлен, контакт доступен. Причина исторического HTTP 400 этим опытом не установлена.
